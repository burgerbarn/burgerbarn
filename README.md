Systems Administrator, 20 years, RHCSA. I like to build robots and self-hosted AI, and I write guides. I like big bots and I cannot lie.
I try to build so the next person can also.

[![lightBot](https://img.youtube.com/vi/S2A089r5JIQ/0.jpg)](https://www.youtube.com/shorts/S2A089r5JIQ)

**[lightBot](https://github.com/burgerbarn/PublicRobot)** — a ROS 2 home robot on a Jetson Orin NX: Nav2 and
SLAM, odometry without wheel encoders, GPU open-vocabulary vision, voice, and a local AI that can propose but
not act. 37-chapter build guide at [wiki.matttesch.com/lightbot](https://wiki.matttesch.com/lightbot).

**[buddy](https://github.com/burgerbarn/buddy)** — native iOS/Android app for the same stack: local LLM,
voice, web search, Home Assistant.

**[opencode-intel-arc](https://github.com/burgerbarn/opencode-intel-arc)** — OpenCode on an Intel Arc laptop
with llama.cpp Vulkan, Podman Quadlet, SearXNG, and the measured numbers.
